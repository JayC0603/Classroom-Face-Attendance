# Livewall

Admin route: `#livewall`, under Vận hành.

- Defaults to the first four enabled, applied cameras; select up to nine.
- Two or three columns, single-camera focus, Escape to restore, fullscreen.
- Desktop fullscreen fits the selected grid into the viewport; mobile stacks tiles.
- Session storage remembers selected camera IDs. Deleted cameras are reconciled every 10 seconds.
- Reuses the recognition endpoint and matching processed-frame overlays, with 500 ms between completed requests per tile. Each tile has one in-flight request, a two-second timeout, preview expiry and unmount cancellation.
- Focus retains mounted streams. Removing a tile or leaving the page releases it. Hidden tabs suspend polling through the existing adapter.
- Browser webcam requires explicit start/permission; its upload stops when the tile unmounts or the tab is hidden. Worker cameras continue independently of the wall.
- Runtime metadata comes from the existing shared connection; unknown/stale status stays explicit.

Validation: targeted frontend tests, production build, and Edge headless visual checks at 1440px and 360px. Browser-only fixtures exercise four/nine feeds, focus, fullscreen, no horizontal overflow, and no page errors. No fixture cameras are persisted to the backend. Actual nine-camera throughput and hardware capacity have not been benchmarked.
